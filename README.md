# :pushpin: Sobre o projeto

Oi! Eu sou a autora deste repositório chamado “Trabalho Lógica de Programação e Algoritmos”, criado para uma atividade prática da disciplina de Lógica de Programação e Algoritmos, do meu curso de Análise e Desenvolvimento de Sistemas.

A ideia principal desse projeto foi colocar em prática os conceitos básicos de lógica de programação, estrutura de dados simples e uso de algoritmos para resolver problemas cotidianos.

---

## :desktop_computer: O que o projeto faz?
O projeto contém alguns algoritmos desenvolvidos em Python que resolvem exercícios típicos, como:

- Entrada de dados pelo usuário
- Processamento de condições (if, else)
- Estruturas de repetição (for, while)
- Uso de funções
- Estruturas de dados: listas, tuplas e dicionários

Cada arquivo do projeto representa um exercício ou problema diferente, todos comentados para facilitar o entendimento do passo a passo.

## :computer_mouse: Como Executar

### 1- Clone este repositório:

```bash 
git clone https://github.com/umaisaduasbeli/Trabalho-Logica-de-Programacao-e-Algoritimos.git
``` 

### 2- Acesse a pasta do projeto:

```bash 
cd Trabalho-Logica-de-Programacao-e-Algoritimos
```

### 3- Excecute o arquivo desejado:

```bash
python nome_do_arquivo.py
```
